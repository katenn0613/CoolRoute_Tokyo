# CoolRoute Tokyo プロジェクト概要

## 目的

CoolRoute Tokyo は、東京の高温環境における徒歩経路を比較する静的 Web アプリです。歩行距離と、道路ごとの公開データから推定した Heat Exposure Score（暑さ曝露スコア）のトレードオフを確認できます。

公開デモ：<https://katenn0613.github.io/CoolRoute_Tokyo/>

## 現在の Demo Area

対象は「皇居東側—丸の内—東京駅」の約 2〜3 km の小領域です。東京全域の道路・緑地・給水地点をカバーするサービスではありません。

## 3 つの経路

- **最短ルート（fastest）:** 道路距離の合計を最小化します。
- **バランスルート（balanced）:** 距離とモデル上の暑さ曝露を折衷します。
- **涼しさ優先ルート（coolest）:** 距離増加を許容しつつ、低いモデル曝露により大きい重みを与えます。

3 ルートは同じ Weighted Dijkstra 実装で計算され、地図上に同時表示されます。大部分が重なる場合も、それは現在の道路とモデルから得られた結果です。

## 使い方

1. 地図内をクリックして出発地を選びます。
2. 2 回目のクリックで目的地を選びます。
3. 計算後、ルートカードで選択中の経路と指標を切り替えます。カード切替で経路計算は再実行されません。
4. 必要に応じて Heat Exposure Layer、Drinking Station Layer、建物による推定日陰を表示します。日陰条件は 09:00、12:00、15:00 から選択できます。

## 指標の読み方

**平均暑さ曝露スコア**は、Edge ごとの Heat Exposure Score を道路長で加重平均した `[0,1]` の比較指標です。

**モデル上の累積暑さ曝露**は `Edge Length × Heat Exposure Score` の合計です。平均スコアが下がっても、迂回が長ければ累積値が増える場合があります。両者は別の指標です。

計算式と用語の詳細は [METHODOLOGY](METHODOLOGY.md) を参照してください。

## データ

- OpenStreetMap の歩行道路ネットワーク
- 東京都の「緑のオープンデータ（GIS データ）」のうち、実際の緑被覆 Polygon と定義できるホワイトリスト対象
- 東京都水道局の Tokyowater Drinking Station
- 国土交通省 Project PLATEAU 千代田区 2023 の公式建築 CityGML

`green_score` は道路 15 m Buffer 内の実緑被覆 Polygon 比率の代理値であり、日陰、樹冠遮蔽率、実測路面温度ではありません。`water_penalty` も最寄り公式給水地点までの距離に基づく代理値であり、経路が給水地点を実際に通過することを意味しません。出典、ライセンス、処理内容は [DATA_SOURCES](DATA_SOURCES.md) に記録しています。

建物による推定日陰は、秋分日 09:00、12:00、15:00 の Project PLATEAU LOD Geometry をオフライン投影した道路中心線上のモデル比率です。リアルタイムの日陰、樹木の日陰、気温低下を示すものではなく、現在の経路コストにも追加していません。

## M7 評価

Random Seed `20260821` で距離別に層化した 90 組の OD を、Production Routing 実装で評価しました。バランスルートと涼しさ優先ルートで、平均スコアと累積値がともに低下したサンプルはそれぞれ 55.6% と 61.1%、3 経路すべてが同一のサンプルは 38.9% でした。サンプルは Trade-off の良さで選別していません。詳細は [M7 評価概要](EVALUATION_SUMMARY_JA.md) を参照してください。

## デプロイ構成

React + Vite + JavaScript で構築し、MapLibre GL JS で地図を描画します。GitHub Actions がテスト、Pages 用 Subpath Build、静的データ検証を実行し、GitHub Pages Artifact として配信します。ルート計算はすべてブラウザ内で実行され、オンラインのバックエンド、データベース、リモート Routing API を使用しません。

## 制限と免責

- OSM の通行情報、公式環境データ、給水地点の状態は変化する可能性があります。
- 現在の Route Exposure Model は気温、湿度、日射、建物や樹木の日陰、個人の健康状態を直接使用していません。M10 の建物日陰は独立した固定時刻の可視化であり、実際の環境はモデル推定と異なる場合があります。
- Heat Exposure Score と Heat Exposure Index は経路比較のためのモデル指標です。熱中症確率、医療リスク、医学的に検証された効果を示すものではありません。
