# Tokyo23 数据覆盖问题汇总（2026-08-22 排查）

> 现象：地图上只有东京**西部/南中部**区域能渲染出热暴露与阴影图层，其余大片区域
> （南部、北部、东部以及都心一部分）没有任何线段。
> 结论：这是**数据管线产物问题**，不是前端或瓦片渲染问题——热暴露/阴影图层是
> 从 Road Graph 的边生成的，图里没有边的区域，图层自然空白。

## 根因与修复建议

1. **Road Graph 覆盖不全是根因**。`scripts/tokyo23/process_road.py` 按 ward 从 Overpass 下载后
   `combined.subgraph(max(nx.weakly_connected_components(combined), key=len))` 只保留最大弱连通分量，
   且下载失败仅记录 `failed_ward_report.json`（进度状态目录已被清理，无法回溯当时哪些 ward 失败）。
   建议：
   - 重新运行 `process_road.py` 前，先检查 Overpass 下载的完整性（每个 ward 的 node/edge 数应 >0）；
   - 用 **admin_level=7 的 23 区边界**逐一验证下载结果，失败时重试而非静默跳过；
   - 排查最大连通分量截断：都心步行网络若因高架/地下通道在 OSM 中不连通，会被整体切掉；
   - 重新生成后重跑 `npm run build:route-a`（二进制图 + 瓦片）即可。
2. **Shade 8 个缺失 mesh**（中央区东部・江東西部）：重新跑 `scripts/tokyo23/process_shade.py` 补齐，
   或把质量标记如实展示（UI 已显示"98.81% 覆盖"说明）。
3. **饮水点 38% 在路网外**：路网补齐后自然解决；在此之前饮水点图层建议按路网覆盖提示。
4. **green_score 76.6% 为 0**：先核对 `environment` 管线是否按全 Tokyo23 处理（元数据中 includedLayers
   是全东京都官方数据）；若确认覆盖完整，则为正常分布，无需处理。

## 前端现状说明

- 热暴露 / 阴影图层已瓦片化（`data/tiles/heat|shade/`），覆盖范围与路网一致——**瓦片本身没问题**。
- 上述缺失只影响"图上有没有线"，不影响已覆盖区域的渲染与路由性能。

## 需要重跑的文件（按依赖顺序）

```
1. scripts/tokyo23/process_road.py       ← 根因修复：重下 23 区 OSM 步行路网
2. scripts/tokyo23/process_green.py      ← 重算 green/water/饮水点 → 重发 graph_tokyo23.json
3. scripts/tokyo23/process_shade.py      ← 补 8 个缺失 PLATEAU mesh → 重发 shade_tokyo23.json
4. npm run build:route-a                 ← 重新生成二进制图 + MVT 瓦片（前端实际读取的产物）
5. scripts/tokyo23/validate_tokyo23.py   ← 校验所有 public 产物
```

依赖关系与注意点：

| 步骤 | 输入 | 输出 | 重跑前必须做的 |
|---|---|---|---|
| `process_road.py` | OSM/Overpass（在线） | `data/processed/tokyo23/graph_schema_1_0_baseline.json` | **删除 `data/processed/tokyo23/road_state/`**（否则已完成区被跳过）；检查 `failed_ward_report.json`；重跑后逐区核对 node 数；复核最大连通分量截断逻辑 |
| `process_green.py` | baseline + `data/raw/` 官方绿地/饮水点（当前为空，需重新准备官方文件） | `public/data/graph_tokyo23.json`、`environment_metadata_tokyo23.json`、`drinking_stations_tokyo23.geojson` | 准备真实官方原始文件（禁止伪造，见 AGENTS.md） |
| `process_shade.py` | 新 `public/data/graph_tokyo23.json` + `data/raw/plateau_tokyo23/`（PLATEAU 官方归档，`download_sources.py` 下载） | `public/data/shade_tokyo23.json` | 删除 `data/processed/tokyo23/shade_state/` 重跑缺失 mesh |
| `npm run build:route-a` | 新的 graph + shade JSON | `public/data/graph_tokyo23.bin(.gz)`、`data/tiles/` | 无（脚本已就绪；瓦片生成逻辑无需改） |
| `validate_tokyo23.py` | 全部 public 产物 | `data/processed/tokyo23/validation_report.json` | 核对各区覆盖断言 |

> `data/raw/` 与 `data/processed/tokyo23/`（进度/缓存）当前都是空的（仅 .gitkeep），原始文件与
> 处理中间产物未入库。重跑前需要重新下载/准备官方原始数据，并注意 `data/raw/` 原始文件不得就地修改。
